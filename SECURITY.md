# Security Policy

Do not disclose security vulnerabilities through public issues. Report them privately to the repository owner with a concise reproduction, impact assessment, affected version, and suggested mitigation. Do not include live credentials, customer data, malware, or exploit payloads in the report.

This project is an educational and portfolio SOC platform. Do not rely on it as the sole security control for a production environment without independent security testing, secure deployment review, and organizational approval.
