# API Documentation

The canonical, version-matched API specification is generated by FastAPI:

- Development: `http://localhost:8000/docs`
- Docker deployment: `http://localhost:8080/docs`
- OpenAPI JSON: `/openapi.json`

## Authentication

Obtain bearer tokens with form-encoded credentials:

```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'username=admin&password=your-password'
```

Pass the response access token on protected routes:

```bash
curl http://localhost:8080/api/alerts \
  -H 'Authorization: Bearer <access_token>'
```

Exchange a refresh token:

```bash
curl -X POST http://localhost:8080/api/auth/refresh \
  -H 'Content-Type: application/json' \
  -d '{"refresh_token":"<refresh_token>"}'
```

## Resource groups

| Group | Prefix | Purpose |
|---|---|---|
| Authentication | `/api/auth` | login, refresh, one-time bootstrap registration |
| Users | `/api/users` | profile and administrator account management |
| Alerts | `/api/alerts` | alert retrieval, status updates, enrichment, Wazuh sync |
| Assets | `/api/assets` | inventory and risk context |
| Incidents | `/api/incidents` | response cases and timelines |
| AI | `/api/ai` | analysis, chat, hunt, reports, playbooks |
| Threat intelligence | `/api/threat-intel` | IOC enrichment and intelligence data |
| SOAR | `/api/soar` | playbooks, executions, approvals, evidence, logs |
| Reports | `/api/reports` | report generation and access |

## Response conventions

- `200` success, `201` created, `204` deleted.
- `401` unauthenticated/invalid token; `403` insufficient role; `404` resource not found; `422` invalid request shape or bounds.
- List endpoints return a `data` collection and pagination `meta` where applicable.
- Never rely on AI-generated content as an authorization decision or destructive automation approval.
